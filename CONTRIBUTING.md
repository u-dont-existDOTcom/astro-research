# Contributions

Keep the research rules, code and aggregate findings reproducible. Describe the
problem and resulting behavior, run the declared checks and record source
provenance. Report negative findings and distinguish historical arithmetic,
engine reproduction and new predictive validation.

Use invented test records. Do not submit birth records, correspondence, database
contents, licensed keyword corpora, interview responses or private result files.
Changes to scoring rules, input selection or statistical endpoints must be
explicitly labeled rather than silently replacing the reproduction baseline.
