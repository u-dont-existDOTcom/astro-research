## Selection and separation

The [selector](../../tools/astrohd/scripts/select_fixed_transfer_models_v01.py) uses only prior development-subject receipts. It enumerates 121 existing standalone HD point-score choices (original structural model, 40 complete-catalogue scores, and 80 source-specific scores) and 1,153 Western point-score choices (direct-sign baseline, 384 fixed planetary-character, 384 conditioned-character/sign/blend, and 384 Lilly). It excludes uncertainty envelopes, joint scores, and later weighting diagnostics without complete fixed-arm standalone ranks. These are the declared candidate models, not all possible interpretations. The two domains use the same ranked grid denominator. For the richer development evidence choose each system's model independently by smallest count scoring higher or equal, then smallest count strictly higher; retain exact co-winners and use a deterministic lexical order if a primary choice is needed. The first metric discourages a trivially maximal but widely tied score. No individual trait weights are newly fitted. Model selection on a known subject is intentionally development, not confirmatory testing.

Before consulting the transfer interview in this run, save the selected tags, development reference scores, ranks, baseline tags, receipt hashes and selector hash to an immutable private receipt. This is a separate-person transfer experiment, not a claim that the individual or chart has never been seen in earlier project work. Existing participant cases may have been used in prior exploratory research; record that exposure. Do not adjust the selected model after examining the transfer outcome. Any later refinement is a new development version, and requires another independent test.

## Executed comparison protocol

The [transfer runner](../../tools/astrohd/scripts/compare_fixed_transfer_models_v01.py) reuses the original verified ephemeris, HD structural intervals, join and location cache. It uses the already frozen scores' component definitions and existing chart-calculation engine, including an exact independent chart-engine calculation at each supplied transfer birth instant. It verifies the exact HD reference geometry and admitted predicates against the interval cache. The exact chart-engine package is a separately authorized archived dependency; the public scorer does not transfer that archive's private data.

Use the selected fixed HD/Western pair, not each candidate's most favorable interpretation. The selected HD adapter supports the source-specific family; the selected Western adapter supports the conditioned Ptolemy family. Other selected families require their corresponding execution adapters. For the Western dispatch, directly evaluate the one selected branch with the same historical terms, sect, aspect and condition calculations as the original all-branches implementation. At the transfer location compute actual Sun longitude and true solar altitude with the same Swiss Ephemeris source for every grid row, checking against the existing geocentric longitude. No use of the development site's horizon at the transfer site. The two original structural/direct-sign models are included as simple comparison baselines, not selected after transfer.

Report full-grid HD and Western higher/tied/lower counts separately, strict improvement in both on the same row, no-lower and tied-both counts, and a separately labeled equal arithmetic mean sensitivity. Include same-date comparisons as a narrower clock discrimination measure; the development UTC day and transfer local day are explicitly distinguished. Preserve the 125 prior HD-boundary abstentions and the complete original grid denominator. Reproduce the selected development reference scores and ranks. Different observation denominators prohibit treating raw cross-person score levels as comparable psychometric measurements.

Interpretation: even a favorable fixed-model transfer on one separately assessed person is exploratory evidence. Prior exposure, incomplete and differently coded items, model-selection multiplicity, reported birth-input disagreement, and possible generic trait/common-carrier effects remain. A poor result is informative and must be reported without choosing a new transfer-favorable model. Neither rank nor lack of strict competitors establishes the empirical probability that astrology is accurate. No personal source, exact birth input, chart score, rank or private receipt locator is published.

## Execution and disposition

The complete original 3,506,400-row scan ran; 3,506,275 timestamps were ranked in the paired models. Exact development reference scores and selected standalone full-grid ranks reproduced. Both predeclared transfer birth-input alternatives were independently calculated and matched their corresponding HD interval geometry. Actual solar position and true altitude were calculated at the transfer location for every timestamp; geocentric Sun longitude parity checked. The frozen pair produced a strong development-case match but did not successfully generalize to the transfer case under the same scoring rules. The broader and narrower admissions and simpler baselines were retained. All individual outcomes are recorded privately rather than published here. No model was re-selected using the transfer outcome.

Five invented-data regressions check tie-aware selection and co-winners, the rank denominator, exact same-row versus marginal comparison, and selected-branch parity with the original full dispatcher. Two tests use the separately authorized chart-engine dependency and are optional when it is not present in the public test environment. The development-selected pair is a failed transfer candidate, not a generally accepted replacement rule. Future evaluation should use independently confirmed birth inputs and comparable observable coverage; define a small number of next candidate hypotheses on development evidence, freeze them, and test on additional respondents who have not informed their selection. This is distinct from the now-superseded every-interpretation dominance objective.
