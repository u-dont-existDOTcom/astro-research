| Document | Purpose |
| --- | --- |
| [Mastro Expert operating guide](mastro/operating-guide.md) | Version, files, settings, keyword trees, inversion, CSV exports, evaluator workflow, checks and troubleshooting. |

The operating guide is the entry point for Mastro procedures. It records
corrections made during the training demonstration as well as the initial
settings, so an earlier demonstration value does not silently override a later
research-specific correction.
